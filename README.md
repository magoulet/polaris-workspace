# Polaris Workspace

Public homepage and privacy policy for the **Polaris Workspace** OAuth application
(a private, single-user Google Workspace automation app).

Served via GitHub Pages:

- Homepage: https://magoulet.github.io/polaris-workspace/
- Privacy policy: https://magoulet.github.io/polaris-workspace/privacy.html

These URLs are supplied to the Google Cloud OAuth consent screen (Branding page)
as the application home page and privacy policy link.
